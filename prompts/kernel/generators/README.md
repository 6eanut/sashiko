# Version-Agnostic Kernel Prompt Generation Question Suites

This directory contains the version-agnostic, identifier-free meta-prompt
questionnaires derived from an LLM root-cause analysis of the last 100,000
`Fixes:` commits in the Linux kernel tree.

## Design Rules

1. **No Function, Struct, or Macro Names:** Questions in this directory must
   never mention specific C/Rust identifiers, `snake_case` symbol names, file
   paths, or kernel version numbers. They express pure architectural,
   synchronization, lifecycle, and contract questions that remain valid across
   all kernel versions.
2. **Actionable & Empirically Grounded:** Every question corresponds to a
   recurring bug pattern observed in the 100,000 `Fixes:` commit corpus and
   instructs the prompt generator what concrete facts to extract from the target
   kernel source tree.
3. **Layered Composition:**
   - **API Guides (`trees/<tree_id>/apis/*.md`)** are generated by answering
     [`api_questions.md`](api_questions.md) against the target release's headers
     and implementation files.
   - **Subsystem Code Contexts (`trees/<tree_id>/contexts/*.md`)** are generated
     by answering both [`subsystem_common_questions.md`](subsystem_common_questions.md)
     (universal questions for all subsystems) and the matching domain module
     under [`domains/`](domains/):
     - [`domains/filesystems_vfs.md`](domains/filesystems_vfs.md)
     - [`domains/memory_management.md`](domains/memory_management.md)
     - [`domains/networking.md`](domains/networking.md)
     - [`domains/storage_block.md`](domains/storage_block.md)
     - [`domains/graphics_drm_media.md`](domains/graphics_drm_media.md)
     - [`domains/drivers_buses_dma_pm.md`](domains/drivers_buses_dma_pm.md)
     - [`domains/arch_virt_bpf_core.md`](domains/arch_virt_bpf_core.md)
